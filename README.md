# CHOICE Markets — Clone

A pixel-faithful recreation of [choice.markets](https://choice.markets/) — an AI-powered prediction market platform built with pure HTML, CSS, and JavaScript.

## 🔴 Live Demo

> Deploy to GitHub Pages or Netlify to go live instantly.

## ✨ Features

- **Authentic design system** — matches original color palette (black, red, gray), noise textures, Aleo/Space Grotesk typography
- **Animated hero section** — live trading feed that cycles through markets, animated bar fills, price tickers
- **Interactive prediction market cards** — YES/NO buy buttons with micro-animations
- **Platform demo section** — simulated trading interface with sidebar + feed
- **Mobile responsive** — pill navbar with hamburger, fluid layouts for all screen sizes
- **Scroll reveal animations** — elements fade in as you scroll
- **Zero dependencies** — pure HTML/CSS/JS, no frameworks

## 📁 Structure

```
choice-markets/
├── index.html        # Main HTML (all sections)
├── styles.css        # Design system & responsive styles
├── script.js         # Interactivity & animations
└── README.md
```

## 🚀 Getting Started

Just open `index.html` in your browser — no build step needed.

```bash
# Or use a local server
npx serve .
```
